# Bikou OS (微光 / びこう)

A privacy-focused fork of Deepin Linux Distribution.

Rebranding from Deepin to Bikou (微光 - "faint light / glimmer").

## Goals
- Full Deepin OS experience
- Enhanced privacy (remove/minimize telemetry, cloud services, data collection)
- Rebrand to Bikou (logo, name, default theme, branding strings)

## Source
Based on Deepin (linuxdeepin org) components.
